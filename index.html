How we score

Each country gets three 0–100 scores. The composite is a weighted average: visa 40%, dollar 35%, speed 25%. Weights are public and deliberately boring — no secret sauce.

Visa accessibility
Does a residency pathway exist for US citizens? How fast does it process? What's the financial floor?
Dollar purchasing power
Cost-of-living index relative to the US. Cheaper = higher score. Data via Numbeo, refreshed daily.
Speed to residency
Months from arrival to permanent residency — not citizenship. Most people optimize this in year one, not year ten.

Source data and the full Python scoring code live in the public repo. We update daily, archive every snapshot, and let anyone reproduce the numbers. If you spot something wrong, open an issue.
